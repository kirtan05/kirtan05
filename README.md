I'm Kirtan Jain, an Android framework and systems engineer at Samsung Research in Noida. I graduated in Computer Science from IIT Patna in 2025.

At work I debug the Android WindowManager and multi-window stack, tracking foldable and split-screen defects down to the commit by comparing Samsung's code against upstream AOSP. I also wrote a Go system that spreads multi-gigabyte SDK builds across a LAN using gossip peer discovery and Merkle-tree reconciliation, which cut a long overseas download to about a third of the time. That code is internal to Samsung, so it is not on this profile.

Outside work I tinker: small tools, self-hosted services and Android apps, mostly things I wanted for myself.

## Projects here

- [spine](https://github.com/kirtan05/spine): a self-hosted reading stack. A kosync-compatible progress sync server on Cloudflare Workers and D1, plus a book ingest pipeline.
- [land-records-app](https://github.com/kirtan05/land-records-app): a Kotlin and Compose Android app, plus the automation behind it, for fetching Gujarat land records from two government portals that sit behind CAPTCHAs.
- [quizfinderindia](https://github.com/kirtan05/quizfinderindia): collects quiz announcements scattered across WhatsApp and Instagram into one searchable feed.
- [BHTC](https://github.com/kirtan05/Balanced-Hierarchical-Text-Clustering-BHTC-): equal-sized hierarchical text clustering, used to allocate hostels for about 800 first-years.
